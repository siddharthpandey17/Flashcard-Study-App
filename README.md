# Recall — Flashcard Study App (Starter)

Responsive flashcard learning app using HTML, CSS and vanilla JavaScript. UI is ready; JavaScript behavior is intentionally left as TODOs.

## Run
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in your browser.
4. Complete TODOs in `script.js`.

## Checklist
- [ ] Show a question and flip to reveal the answer
- [ ] Navigate previous/next cards
- [ ] Add, edit and delete flashcards
- [ ] Mark cards as known or needing practice
- [ ] Update review statistics
- [ ] Persist cards with localStorage

## Concepts
DOM, events, arrays, objects, conditional rendering, forms, localStorage and keyboard events.
